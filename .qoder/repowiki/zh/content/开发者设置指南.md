## 简介

蓝鲸数据库管理平台（DBM）是一个集成多种数据库组件全生命周期管理的系统，支持MySQL、Redis、ES、Kafka、HDFS等多种数据库技术。本指南为新贡献者提供从零开始搭建开发环境的分步说明，涵盖代码克隆、依赖安装、数据库配置和开发工具设置等关键步骤。

## 开发环境搭建

### 克隆仓库

首先克隆蓝鲸DBM主仓库到本地开发环境：

```bash
git clone https://github.com/TencentBlueKing/blueking-dbm.git
cd blueking-dbm
```

### 安装依赖

项目包含Go和Python两种技术栈的服务，需要分别安装对应的开发工具和依赖。

#### Go环境要求
- Go版本：1.24.2（根据go.work文件指定）
- 推荐使用Go官方安装包或gvm等版本管理工具

#### Python环境要求
- Python版本：3.11.10至3.12之间（根据pyproject.toml指定）
- 建议使用virtualenv或conda创建隔离的Python环境

## 代码风格与预提交钩子

### 预提交钩子配置

项目使用pre-commit框架来确保代码提交前符合编码规范。安装和配置步骤如下：

```bash
# 安装pre-commit并设置钩子
cd dbm-ui
./bin/install_precommit.sh
```

该脚本会自动安装pre-commit并配置Git钩子，确保每次提交代码时自动执行代码格式化和检查。

### 代码风格规范

#### Python代码风格
- 代码格式化工具：black（行长度119字符）
- 导入排序工具：isort（多行输出模式3）
- 静态检查工具：flake8（忽略W503和E203以兼容black）

相关配置位于：
- black配置：pyproject.toml中的[tool.black]部分
- isort配置：pyproject.toml中的[tool.isort]部分  
- flake8配置：dbm-ui/backend/.flake8文件

#### 提交信息规范

项目使用commitlint进行提交信息格式验证，遵循常规化提交（conventional commits）规范，确保提交历史清晰可读。

## Go服务开发设置

### 工作区配置

项目使用Go工作区模式（go.work）来管理多个Go模块。主要的Go服务位于dbm-services目录下，包括：

- bigdata/db-tools/dbactuator：大数据工具执行器
- mysql/db-tools/dbactuator：MySQL工具执行器  
- redis/db-tools/dbactuator：Redis工具执行器
- common/db-config：数据库配置服务
- k8s-dbs：Kubernetes数据库服务

### 构建过程

每个Go服务都有自己的Makefile和构建脚本。以dbactuator为例：

```bash
cd dbm-services/bigdata/db-tools/dbactuator
./build.sh
```

build.sh脚本会执行文档生成和make命令来编译服务。

## Python后端开发设置

### 依赖管理

项目使用Poetry进行Python依赖管理。安装依赖的步骤如下：

```bash
cd dbm-ui
poetry install
```

主要依赖包括：
- Django 4.2.23：Web框架
- djangorestframework：REST API框架
- PyMySQL：MySQL数据库驱动
- celery：异步任务队列
- gunicorn：生产级WSGI服务器

### 环境变量配置

开发环境需要设置必要的环境变量。参考bin/environ.sh脚本：

```bash
cd dbm-ui
source bin/environ.sh
```

关键环境变量包括：
- APP_ID：应用ID
- APP_TOKEN：应用令牌
- DJANGO_SETTINGS_MODULE：Django设置模块
- BK_LOG_DIR：日志目录
- BK_IAM_SKIP：跳过IAM认证（开发环境）

## 运行测试

### Python测试

使用pytest运行Python测试套件：

```bash
cd dbm-ui
./bin/pytest.sh
```

或直接运行：

```bash
pytest backend/tests --cov
```

测试配置位于pytest.ini文件，包括：
- 测试路径：backend/tests
- 跳过迁移：--no-migrations
- 复用数据库：--reuse-db
- 代码覆盖率：--cov

### Go测试

Go服务的测试通常集成在构建过程中。以db-config为例：

```bash
cd dbm-services/common/db-config
# 运行单元测试
cd internal/service/simpleconfig && go test -v . 
cd internal/repository/model && go test -v .
cd pkg/validate && go test -v .
```

## 构建与启动服务

### 启动Python后端

```bash
cd dbm-ui
source bin/environ.sh
python manage.py runserver 0.0.0.0:8000
```

### 数据库配置

开发环境的数据库配置位于config/dev.py：

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.mysql",
        "NAME": os.environ.get("DB_NAME", "bk-dbm"),
        "USER": os.environ.get("DB_USER", "root"),
        "PASSWORD": os.environ.get("DB_PASSWORD", ""),
        "HOST": os.environ.get("DB_HOST", ""),
        "PORT": os.environ.get("DB_PORT", ""),
    }
}
```

确保MySQL服务已启动并创建相应的数据库。

### 启动Go服务

不同Go服务有不同的启动方式。以db-config为例：

```bash
cd dbm-services/common/db-config
./bkconfigsvr >>logs/main.log 2>&1 &
echo $! > svr.pid
```

## 故障排除

### 常见问题

1. **pre-commit安装失败**
   - 确保pip已正确安装
   - 检查网络连接和PyPI镜像源

2. **Python依赖安装失败**
   - 确保使用正确的Python版本（3.11.10-3.12）
   - 检查Poetry是否正确安装

3. **数据库连接失败**
   - 检查MySQL服务是否运行
   - 验证数据库凭据和网络连接
   - 确认数据库已创建

4. **Go构建失败**
   - 确保Go版本为1.24.2
   - 检查模块依赖是否完整
